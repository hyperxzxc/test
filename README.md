# Замер скорости загрузки

Консольная утилита на TypeScript и NestJS. Выполняет 10 последовательных GET-запросов к одному URL и выводит среднее время запроса, общий объём и скорость загрузки

## Запуск

Требуется Node.js 22.13 или новее в ветке 22.x либо Node.js 24+

```sh
npm ci
npm run build
npm start -- "https://example.com/"
```

Для замера на большом объёме передайте прямой URL файла, например изображения. Поддерживаются HTTP и HTTPS. После сборки можно запустить CLI напрямую командой `node dist/main.js "https://example.com/"`

Для запуска в Docker

```sh
docker build -t download-benchmark .
docker run --rm download-benchmark "https://example.com/"
```

## Как считаются метрики

- Среднее время запроса в миллисекундах — сумма длительностей, делённая на 10. Каждый замер идёт от отправки GET до полного чтения тела ответа
- Общий объём в байтах — сумма размеров полученных тел. Клиент считывает тела потоком, исключает заголовки и служебные данные HTTP и запрашивает ответ без сжатия. Если сервер всё же вернёт сжатое тело, учитываются полученные байты
- Скорость в MiB/s — общий объём в мебибайтах, делённый на суммарное время запросов в секундах. Один MiB равен 1 048 576 байтам. Время ожидания ответа входит в расчёт

Каждый запрос ограничен пятью минутами, включая скачивание тела. При редиректе, другом ответе вне диапазона HTTP 2xx, сетевой ошибке, обрыве тела или тайм-ауте серия завершается с кодом 1 и номером запроса в stderr. Неверный аргумент возвращает код 2

## Проверка

```sh
npm test
npm run lint
npm run typecheck
npm run format:check
```

Unit-тесты Vitest проверяют формулы и граничные случаи. Интеграционные тесты запускают собранный CLI и локальный HTTP-сервер, проверяют число запросов, последовательность чтения, объём и обработку ошибок. Тайм-аут проверяется с коротким лимитом через HTTP-адаптер
